# Security

This repository holds documentation and configuration examples; it runs no code. If you find a
problem in Nexa Agora itself, or a guide here that would lead a reader into an unsafe setup,
do not open a public issue.

- Email **<security@nexaethos.com>** with a description, where you found it and how to reproduce
  it. Never include a connection key, a token or company records.
- You will get an acknowledgement, and a fix or an answer with its reasoning.

A connection key that was committed, pasted or shared is compromised: revoke it in Agora at
once and create a new one. Deleting the latest copy does not remove it from Git history.
